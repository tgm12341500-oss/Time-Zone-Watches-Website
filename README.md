# Time Zone | Premium Watches Store

A modern, responsive e-commerce website developed to showcase premium watches through an elegant interface, structured product sections, and a user-friendly browsing experience.

## Live Demo

**[Explore Time Zone](https://tgm12341500-oss.github.io/Time-Zone-Watches-Website/)**

## Overview

Time Zone is a front-end web development project focused on building a visually appealing and responsive online watch store. The website features a clean layout, organized product displays, and responsive navigation to provide a consistent browsing experience across different screen sizes.

## Key Features

- Responsive layout optimized for desktop, tablet, and mobile devices.
- Modern navigation bar with shopping-related icons.
- Dedicated product showcase and New Arrivals sections.
- Product gallery with visual content.
- Watch collections and promotional sections.
- Consistent styling and structured page layout.

## Technologies & Tools

- **HTML5** – Semantic page structure.
- **CSS3** – Custom styling, layouts, and responsive design.
- **Bootstrap 5** – Responsive framework and layout utilities.
- **JavaScript** – Bootstrap interactive components.
- **Font Awesome** – Interface icons.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/tgm12341500-oss/Time-Zone-Watches-Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Time-Zone-Watches-Website
   ```

3. Open `index.html` in your browser.
